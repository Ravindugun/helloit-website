# Hello IT - Website

Static website for Hello IT. No backend is required.

## Files
- `index.html` - main page
- `style.css` - design and responsive layout
- `script.js` - navigation, animations and email support form
- `assets/` - brand logo files

## Before going live
Edit the `SITE` object in `script.js` and replace the empty values for:
- phone
- whatsapp
- website
- facebook

Also update any text in `index.html` where service area wording needs to be more specific.

## Hosting
Upload the files to your Nginx web root, for example:
`/var/www/helloit/`

This project does not need Node.js, React, a database or PHP.
